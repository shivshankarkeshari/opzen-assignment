# Five-minute reviewer demonstration

Start services and load the bundled five PDFs using the README. Wait until all five are ready. They are synthetic financial policies/procedures, including one restricted delegation register. PDF 2025/2026 versions are deliberately distinct fixture uploads; to demonstrate daily revisions of one logical document, use Add revision on an existing upload.

1. **Ingestion and evidence:** open Documents, inspect the 2026 policy, extraction, chunks, tables and source locators. Use Search for onboarding retention, Read subsection and Open exact revision. Show the seven-year minimum and legal-hold qualification. DOCX and scanned-PDF fixtures can also be generated with `uv run python -m scripts.demo_data` and uploaded manually; the financial gold set itself contains native-text PDFs.
2. **Continuation:** ask about approvals for an urgent INR 1,500,000 settlement under subsection 4.2, including its continuation. Expected: both Director of Finance and independent Risk Controller, no self-approval. Open the continuation spanning pages 2–3.
3. **Investigation and follow-up:** investigate the currently named approvers using FCP-2026, EXC-2026 and DR-2026. Expected names: Meera Sethi and Arjun Rao, subject to delegation validity and case preconditions. Follow up with INR 2,500,000; CFO Leena Shah must additionally countersign.
4. **Comparison and human review:** select the 2025 and 2026 policy revisions and compare retention (5 versus 7 years). Investigate FCP-2026 against RDS-2026: a seven-year minimum conflicts with a five-year maximum for the same files. Precedence is not established. Demonstrate Confirm/Dismiss/Unresolved with a rationale; it is a report-level human review, not a legal decision. Contrast the compatible five- and seven-year minimum rules.
5. **Failure and access control:** ask for FY2027 revenue; the documents do not supply a forecast, so inspect limitations instead of accepting Q1 2026 as a substitute. Switch to reviewer: four documents are visible and the private register is absent. Ask for named register holders; accessible sources must not reveal them. An invalid file or unavailable provider can separately demonstrate explicit processing/model failure. These are expected behaviors, not guarantees that every configured model reasons correctly.
6. **Daily change:** as owner, Add revision to a document, process it, and inspect its revision history. Compare historical/current scope and the freshness label on an earlier answer. Published revisions are immutable. Reprocessing makes a processing revision; it does not overwrite evidence. Permission revocation causes source/result access checks to run again.
